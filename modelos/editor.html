Propriedades

Selecione um elemento para editar. Arraste caixas e textos para reposicionar. As ligações acompanham os componentes.

Atalhos no desenho
Ctrl+C: copiar selecionado
Ctrl+V: colar no editor
Ctrl+Z: desfazer

Nos campos de texto, os atalhos mantêm seu comportamento normal.

Salvar e reabrir
“Salvar projeto” baixa um JSON com os quatro cenários. “Abrir projeto” recupera esse arquivo para continuar a edição.

O rascunho também fica salvo neste navegador quando o armazenamento local está disponível. Exporte o JSON para manter uma cópia permanente.
